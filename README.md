# Quiz App

A simple and interactive Quiz Application built with HTML, CSS, and JavaScript.

## Features

* Multiple-choice questions
* Dynamic question loading
* Score tracking system
* Final results screen
* Responsive and user-friendly interface
* Modern UI with animations and styling

## Technologies Used

* HTML5
* CSS3
* JavaScript (DOM Manipulation)

## How It Works

1. The quiz displays one question at a time.
2. Users select an answer from four options.
3. Clicking **Next** moves to the next question.
4. Correct answers increase the score.
5. After the final question, the application displays the user's score and quiz completion message.
